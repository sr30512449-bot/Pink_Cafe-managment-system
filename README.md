☕ Pink Cafe Management System

📌 Project Description

Pink Cafe Management System is a group project designed to manage cafe operations, menu items, billing, and daily sales.

🎯 Project Objectives

- Manage cafe menu items.
- Organize customer orders.
- Manage billing and payments.
- Record daily sales.
- Improve cafe management.
